# Camp-Sec MVP

## 1. MVP Definition

The Minimum Viable Product is a functional web-based campus security incident reporting and management system.

The MVP demonstrates the complete incident lifecycle from reporting through security review, investigation, status updates, and reporter tracking.

## 2. MVP Users

### Student

- Register
- Login
- Report an incident
- View own incidents
- Track incident status

### Staff

- Register
- Login
- Report an incident
- View own incidents
- Track incident status

### Security Officer

- Login
- View incidents
- Review incidents
- Investigate incidents
- Update incident status
- Record actions

### Security Supervisor

- Monitor security incidents
- Review security activity
- Support management of incidents

### Management

- View authorized incident summaries and reports

### System Administrator

- Manage users and roles
- Support system administration

## 3. MVP Features

- Authentication
- Role-aware access
- Incident reporting
- Incident storage
- Incident details
- Incident status tracking
- Security officer incident management
- Incident actions/history
- Search and filtering
- Basic reporting
- Basic notifications where required

## 4. Incident Status

The MVP can use:

```text
Submitted
Under Review
Under Investigation
Resolved
Closed
```

## 5. MVP Acceptance Workflow

```text
1. Student/staff registers.
2. User logs in.
3. User reports an incident.
4. Incident is stored in the database.
5. Security personnel view the incident.
6. Security personnel review/investigate it.
7. Security personnel update the status.
8. Security personnel can record an action.
9. Reporter can view the updated status.
```

## 6. Out of Scope for MVP

- Mobile app
- CCTV integration
- Live GPS tracking
- AI classification
- Advanced analytics
- External SMS infrastructure
- Full emergency dispatch integration
- Physical patrol management

## 7. MVP Success Criteria

The MVP is successful when the core incident lifecycle works reliably from reporting to management and status tracking.
