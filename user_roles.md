## 7. Access Principle

A role determines what a user is allowed to see and do.

```text
Authentication
      ↓
Identify user
      ↓
Determine role
      ↓
Apply permissions
      ↓
Allow / deny operation
```

Frontend role checks improve the user experience.

Backend/database authorization must ultimately enforce sensitive permissions.
